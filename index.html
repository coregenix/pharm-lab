An open catalog of experimental pharmacology models rebuilt as browser simulations — same protocols, doses, and readouts your lab manual expects, none of the animal cost. Pick a model below, choose a drug and dose, run the trial, and read the data the way you would from a real bench.

Bureau-style CAL software, reimagined as a static, open-source web app — built for GitHub Pages. ● live = interactive simulation available · ○ planned = on the roadmap, contributions welcome. See README for how to add a model.
