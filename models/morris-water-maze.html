Learning & Memory · Spatial Memory Model

Morris Water Maze

A rodent swims in a circular pool of opaque water to find a submerged, hidden escape platform, using distal spatial cues. Over repeated trials, escape latency normally falls as spatial learning improves. Amnesic agents (scopolamine) impair learning and increase latency; nootropics improve it, even against a scopolamine-induced deficit.
